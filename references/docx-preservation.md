# Word编辑与保护检查

## 选用现有环境

若有工作区依赖加载器或文档技能，先加载其支持的工具和运行时；不要硬编码作者电脑上的路径。可用成熟Word控制工具或Python/OOXML局部修改，前提是保留用户禁止改变的内容。本技能随附审计脚本只依赖Python3标准库，不负责生成或修改Word。

编辑复杂DOCX前检查ZIP部件、正文块、嵌套表、内容控件、目录域、书签、图片关系、分节以及页眉页脚。`python-docx`的`document.paragraphs`并不能覆盖内容控件、全部文本框、复杂域和图片内容；由提取文本重建整本文件容易丢失原目录。

## 增补模式

复制原文件，在明确节点前后插入新内容。能通过现有工具可靠增补即可；复杂原件优先直接修改OOXML并原样复制未涉及的ZIP部件。

- 保留原`w:sdt`目录内容控件、目录字段、标题编号、分页符、分节符、原有空段、页眉页脚及图表。不得因看似冗余自动清理。
- 新素材标题用独立样式及`keep_with_next`，默认不设置会进入原TOC范围的大纲级别。需更新目录条目时先有用户授权；更新页码不等于允许重建目录。
- 一段包含多张独立素材时，不按图片文件数随意拆段。确需拆分，在原run边界处理，保留原`pPr`、全部原节点顺序和图片属性，记录可逆合并方法。
- 图片字节不变仍可能显示改变。保护引用次数、顺序、尺寸、裁切、旋转、浮动/嵌入方式、定位和环绕属性；不把残留在ZIP但不再被引用的图片算作已经保留。
- 不将浮动图或固定行高一律改成新设置。新增标题挤占空间时先调整新增部分间距；必要的原布局改变需在用户授权范围内并记录。

### 内容保留验证

建立新增节点清单及必要变动白名单。将最终稿副本中的新增节点撤销、目录页码缓存还原，并逆向合并获准拆分的段落后，比较原正文的规范化XML/节点结构；未涉及的部件应一致。若工具正常化重写了XML，应进行等价语义比较，不能把未知差异都当正常。

不要把“只有document.xml可变”作为通用硬规则：新增样式或关系可能合理改变其他部件。逐部件说明授权用途，并保持原有定义和引用有效。

## 仅修改指定列

先锁定当前索引表、表头、行以及实际单元格。存在`gridSpan`或`vMerge`时，视觉列号不一定等于XML中第几个`w:tc`，先还原表格网格。

建立允许修改的单元格清单。中列只改必要文字；右列复用或修复当前正确的目标，不重新编号全部材料。不要使用`cell.text = ...`或`paragraph.text = ...`无差别清空含域、超链接或复杂格式的单元格。必要时局部替换文本run，或在该获准单元格内重建已核对的链接结构。

验收时将获准单元格恢复成修改前版本，再比较整个文档与原件，验证表头、左列、网格、其他单元格、正文和图件未变。已有无关错误只记录，不扩大白名单。

## 链接与目录

- 书签名称使用稳定、合法的短标识，如`BID_M0001`；在全文件中检查名称和ID唯一，起止配对。显示标题、素材编号和书签名分别维护。
- 同时识别`w:hyperlink/@w:anchor`、简单域`HYPERLINK \\l`和跨多个run的复杂域。`PAGEREF`/`REF`也可能引用书签，域指令不能按单个`instrText`片段盲改。
- 每个标签都要核对实际落点，而不只是“目标存在”。优先跳到材料的小标题及首张有效页；同一组合材料可以共享书签。
- 若有打印页码，先渲染最终内容，依据书签实际落页更新`PAGEREF`缓存或目录缓存，再渲染复查。不要拿原版页码填新版，不用整篇纯文本目录替换原目录域。
- 渲染软件可能自动计算字段但不保存DOCX缓存；应同时检查交付DOCX里的缓存与最新渲染页码。只写“打开后手动更新目录”不算完成本可执行的刷新工作。

## 审计脚本的定位

```text
python scripts/audit_docx.py source.docx --out before.json
python scripts/audit_docx.py source.docx result.docx --out comparison.json
```

输出供代理分析，不必全部交给用户。退出码0只表示审计报告写入成功，必须继续读取报告中的差异与完整性问题，不能等同于文档验收通过。检查图片真实引用而非仅media库存、目录和字段是否消失、书签及内部链接是否有效，以及改变了哪些ZIP部件。脚本未报告异常不代表指定列以外一定没有改动，更不代表图片内容已阅读、证据结论正确或页面没有裁切。授权变化与范围外缺陷需要人工结合改动清单判断。

## 最终渲染

按可用文档技能执行渲染；没有专用技能时使用环境支持的Word或兼容渲染器输出页图。逐页检查受影响页面：原目录、索引换页、长表头、标题与素材分离、图件/签章完整性、跨页表格、空白页和页码。只在已证明页面像素相同且存在此前视觉检查时复用检查结果。

若渲染后中文消失或变成方框，先核查源文和渲染器可用的中文字体配置，区分环境缺字与文档缺字；不要为修复预览而擅自给原标书全文换字体。

交付校验绑定最终文件指纹和最终渲染版本，不拼接不同版本的页数和验证记录。PDF、页图、差异报告留作工作底稿，用户没有要求时只交Word和改动明细。
